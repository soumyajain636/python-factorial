# Factorial in Python

## About the Project

This repository contains `factorial.py`, a beginner-level Python program focused on the concept of factorials.

The factorial of a non-negative integer \(n\), written as \(n!\), is the product of all positive integers from 1 to \(n\). By definition, \(0! = 1\).

## How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open a terminal in the repository directory.
4. Run the following command:

```bash
python factorial.py
```

If your system uses `python3` to run Python, use:

```bash
python3 factorial.py
```

## Learning Objective

The objective of this program is to understand the factorial concept and practise basic Python programming.

By exploring this program, beginners can develop their understanding of mathematical operations and how Python can be used to solve mathematical problems.
